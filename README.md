

Программа сортирует большой бинарный файл, содержащий 32-битные целые числа.
Файл не содержит заголовка: числа записаны подряд, каждое число занимает 4 байта.

Результат создается в той же директории, что и исходный файл.
Например:

```text
numbers.bin -> numbers_sorted.bin
```

## Запуск

Программа принимает два параметра:

```bash
python sort.py input_file.bin max_numbers
```

где:

- `input_file.bin` - имя исходного бинарного файла;
- `max_numbers` - максимальное количество чисел, которое программа может одновременно использовать в памяти.

Пример:

```bash
python sort.py numbers.bin 1000000





## Алгоритм

Используется внешняя сортировка.

1. Сначала программа проверяет входные параметры и размер файла.
2. Затем файл делится на части.
3. Каждая часть читается в память и сортируется в отдельном процессе.
4. Отсортированные части сохраняются во временные файлы.
5. Потом временные файлы сливаются с помощью кучи (`heapq`).
6. Итоговый отсортированный файл записывается в ту же директорию.
